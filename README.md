# 基于产品“智游北京 · AI旅行管家”的数据分析

**指标体系搭建 → SQL 取数 → Python 分析 → 业务结论落地**

**2026挑战杯北京市三等奖的数据分析复盘**

## 项目背景

「智游北京·AI旅行管家」是一款面向北京旅游市场的智能路线规划Web应用：用户输入旅行需求或选择主题标签（文化古迹 / 亲子研学等），
AI 自动串联景点生成一日游行程，结合高德地图完成路线规划与导航跳转，并支持景点收藏、足迹打卡、
门票/酒店/套餐预订。 **我是该项目的负责人**。

赛后复盘过程中，我们发现项目在商业化论证方面有所欠缺，于是我以本项目为载体，独立进行了一个完整的产品数据分析，重点聚焦解决以下三个问题：**用户从哪来、在哪流失、钱该怎么花**。

## 数据说明

产品处于内测阶段，未全量上线，故本项目数据为**基于产品功能逻辑构造的模拟埋点数据**
（生成规则复刻真实业务规律：渠道间转化差异、周末效应、留存衰减、冲动型渠道高退款等）。
分析方法论、指标体系、SQL 与 Python 实现均为真实完成，可直接迁移至真实业务数据。

| 表 | 规模 | 说明 |
| --- | --- | --- |
| `users.csv` | 8,000 行 | 用户维度：注册时间、获客渠道、城市线级、设备、年龄 |
| `events.csv` | 499,623 行 | 埋点事件：会话ID、用户ID、时间、事件名、渠道 |
| `orders.csv` | 13,644 行 | 订单：产品类型、金额、支付/退款状态、渠道 |

**事件链路**：`app_launch` → `ai_plan`（发起AI规划）→ `view_spot`（看详情）→
`add_favorite`（收藏）→ `create_order` → `pay_order`

## 指标体系

- **业务目标（OSM）**：净 GMV 的可持续增长，按 AARRR 拆解到获客 / 激活 / 留存 / 变现 / 传播五环节
- **北极星指标**：周活跃规划用户（WAU-Plan）——"成功生成一条行程"是用户感知价值的核心瞬间，
前置于收藏、预订与分享，且可被产品/运营/市场动作直接撬动

## 分析模块与核心结论

| 模块 | 方法 | 关键发现 |
| --- | --- | --- |
| 增长监控 | 北极星指标 + LAG 周环比 | 增长由投放驱动，投放收缩即回落，自然增长引擎未建立 |
| 漏斗诊断 | 会话级 AARRR 漏斗 | 整体转化 5.4%；「规划→详情」流失 41% 是最大杠杆点 |
| 渠道评估 | 分渠道漏斗 + ROI | 抖音"量大利薄"（转化 1.9%、退款率 11.1%）；微信裂变质优（转化 11.6%，6 倍于抖音） |
| 留存分析 | 注册周 Cohort | 次留 52.4% / 7留 32.0% / 30留 13.0%；D7→D14 陡降是品类性短板 |
| 用户分层 | RFM（NTILE 三分位） | 「重要唤回用户」333 人、人均 ¥803，是单客杠杆最高人群 |
| 交易分析 | 产品结构 + LEAD 复购 | 酒店以 34.7% 订单量贡献 53.7% 净GMV；首单 30 日复购率 43.1% |
